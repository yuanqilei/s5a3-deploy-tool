# 首次部署与交付给其他人（2026.11.21.2）

这是可独立运行的 Windows 工具，已内置通用启动器模板和首次网关初始化组件，无需 Python、Go、Flutter 或 AI。服务器使用受支持的 Linux/Docker 环境，公网安全组与服务器账号由服主准备。

## 第一次使用

1. 解压工具到可写目录，填写自己的服务器 IP、SSH 用户和密码，检测连接并保存配置。
2. 选择匹配的完整客户端目录（同时包含 DNF.exe 和 Script.pvf），并在游戏服页选择部署 PVF。
3. 第 1 页「游戏服务端」部署游戏服，等待健康检查成功。
4. 第 4 页「GM」执行部署。工具自动克隆网关源码、生成证书与签名密钥、建立专用数据库账号、准备 Compose 配置、构建镜像、初始化索引和管理表，再启动网关。首次索引可能需要十余分钟。
5. 成功后自动导出工具旁的「玩家启动器」目录，并上传 EXE 与 ServerS5A3-1.0.18.zip。把 ZIP 发给玩家，解压后将 PurpleMagic.exe 与 PurpleMagic.profile.json 放在同一目录。不要只发送通用 EXE。
6. 第 3 页「登录器服务端」可检查通讯文件、发布后续版本和启动登录器。通讯配置变化后，重新分发导出的配套 ZIP。

## 日常更新

游戏服更新在第 1 页操作；GM/网关更新在第 4 页操作。已有部署保留签名私钥、证书与配置；不应为普通更新删除数据目录。残缺目录会明确报错并保留现场，而不会自动清空重建。

## 发给别人哪些文件

工具交付包只包含 EXE、使用说明、版本及哈希，不含服主的 s5a3_config.json、日志、备份或玩家数据。首次运行会生成个人配置，不能再把运行后的整个目录直接转发给其他服主。

PurpleMagic.profile.json 是每台服自己的本地信任配置，仅含公开连接地址、公钥、证书及资源摘要；应随玩家启动器成套交付。服务器上的签名私钥、TLS 私钥、数据库口令和管理 Token 不进入玩家包。

## 常见失败

- /launcher 返回 000：网关没有监听或连接失败；新版不会提示发布成功。
- 找不到 profile：先完成第 4 页网关部署，确认网关数据目录设置正确。现代 Compose 默认 /opt/purplemagic/data2。
- PVF 不匹配：核对本机客户端与游戏服务端的精确 SHA256，再继续。
- 公网不通但本机探测通过：检查云安全组和外部网络；工具的服务器 loopback 检查不能代替第三方公网验收。

公网服务器会自动使用「宣告 IP」（留空则使用服务器 IP）生成对外地址；内网部署保留原模式。更新公网配置前自动备份运行配置，保留原实例身份与数据库凭据。
