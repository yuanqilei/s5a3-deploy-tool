# 连接与更新诊断

`2026.11.20.6` 根据实际日志修正两条连接路径：

- `No existing session` 出现在 SSH 连接阶段，部署尚未执行。TCP 建连单独限制 10 秒，SSH 传输等待 60 秒、标识等待 30 秒、认证等待 30 秒，避免短传输等待先于标识超时而给出模糊错误；失败时区分端口、握手和密码认证，并关闭未就绪的连接。
- 更新检查 `[Errno 2] No such file or directory` 在打包 EXE 中可复现，完整 traceback 指向 SSL 上下文加载构建解释器配套数据。统一 PyInstaller spec 收集该公共证书数据，保持完整证书校验；所有构建入口使用同一 spec。

程序日志自动保存到 `%LOCALAPPDATA%/S5A3/logs/`，底部“打开日志目录”可查看。记录工具版本、任务输出和异常栈；已知连接密码、密码/Token 字段和 URL 用户凭据在写入前脱敏。日志不可写不会中断部署。单个日志文件最多约 20 MB。

冻结程序联网验证：

```text
S5A3服务端管理.exe --network-selftest <输出报告.json>
```

此命令在实际 EXE 内创建 SSL 上下文并读取、验证公开签名更新清单，不连接游戏服务器，不读取连接口令，不部署服务。若旧版更新检查失败，需要首次手动换装 .6，之后才能正常检查新版。

SSH 并非通过增加超时就能保证连接：本次对所提供服务器的只读探测在 TCP 建连后等待 45 秒仍未收到 SSH 标识，尚未进入密码验证。没有进入服务器或修改其文件；应继续从云控制台核查 sshd 和网络链路，不能将其诊断为数据库、PVF 或初始化错误。
